
# Catálogo Digital de Procesos

Sistema web desarrollado durante mis prácticas profesionales, enfocado en la organización y consulta de procesos de control de calidad de diferentes equipos.

## Descripción

El Catálogo Digital de Procesos tiene como objetivo facilitar el acceso a información relacionada con los procedimientos de revisión y control de calidad.

La aplicación permite organizar los procesos por tipo de equipo y consultar la información de manera sencilla.

## Funcionalidades

- Consulta de procesos de control de calidad.
- Clasificación de procesos por equipos.
- Registro de nuevos procesos.
- Edición de procesos existentes.
- Eliminación de registros.
- Visualización de información mediante una interfaz web.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Ejecución local

El proyecto utiliza PHP y MySQL, por lo que requiere un servidor local compatible.

Para utilizar las funciones que dependen de la base de datos, es necesario configurar la conexión y disponer de una base de datos compatible.
